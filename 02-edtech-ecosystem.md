# 02 · AI EdTech Ecosystem

**Origin:** training build
**Role:** AI automation & EdTech architect
**Designed for:** 1,000+ students

## Problem

An online marathon with a large cohort needs assignments delivered, submissions checked and feedback written — at scale that is physically impossible for an admin.

## Solution

- **Registration:** Airtable with a unique access code per student
- **Lesson delivery:** ManyChat flows synced with Airtable, time-triggered
- **Feedback:** OpenAI analyses each student's answer in real time → personalised comment
- **Dashboard:** one Airtable base — every participant's progress in one place
- **Channel:** Telegram

## Result

The full student journey — registration → lessons → AI feedback — runs without an admin in the loop.

`ManyChat` `Airtable` `OpenAI` `Telegram` `Make`
